# GitHub 公開前の確認

このフォルダーは公開用の文書案です。GitHub への反映はまだ行っていません。

## 公開対象

`README.md`、`troubleshooting.md`、`reproduction.md`、`cleanup.md`、`publishing.md`、`.gitignore` の 6 ファイルだけを対象にします。

## 公開前チェック

- [ ] GitHub 接続アカウントと対象リポジトリの owner/name を確認する。
- [ ] リポジトリの公開範囲、反映先ブランチ、新規作成または既存更新かを確認する。
- [ ] 対象 6 ファイルの差分を確認し、この内容の反映について利用者の承認を得る。
- [ ] 秘密鍵、AWS キー、トークン、認証設定、実 IP、アカウント ID、ARN、リソース ID、請求書、生ログが含まれていないことを確認する。
- [ ] 画像を追加する場合はブラウザのアドレス欄・アカウント表示・識別子も確認し、加工後の画像を再確認する。
- [ ] `.gitignore` は既に追跡中のファイルや過去コミットを削除しないため、既存リポジトリでは履歴・ステージ内容も確認する。

リポジトリの場所と承認が確定してから、対象ファイルを明示して追加・コミット・反映します。`git add .` による一括追加は避けます。秘密情報を誤って公開した場合は、削除だけで済ませず認証情報の失効・再発行を優先します。
